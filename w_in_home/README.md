# w_in_home – Phong cách Liêm (WSL)

## Cài đặt

Chạy trong WSL:

    cd /mnt/d/GitHub/wsl/w_in_home
    bash install.sh

## Tính năng

- Loading thiền: Nam Mô A Di Đà Phật
- Prompt màu + git branch
- Alias:
  - ll: list đẹp
  - np: mở Notepad Windows
  - ex: mở Explorer
  - wslhome: nhảy về folder cấu hình
